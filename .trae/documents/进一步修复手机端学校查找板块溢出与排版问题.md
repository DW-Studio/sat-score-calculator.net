## 目标
- 彻底消除手机端内容溢出，保证大学名称完整显示且排版紧凑，无需横向滑动。

## 仅改 CSS（style.css）
- 容器与版块
  - 在手机端限制宽度与内边距：`.schools-section { padding: var(--spacing-md); max-width: 100%; overflow: hidden; }`
  - 保证头部与元信息行不溢出：`.school-header, .school-meta { width: 100%; }`
  - 卡片最大宽度：`.school-card { max-width: 100%; }`
- 过滤栏与输入
  - 竖排栈叠：`.filters-bar { grid-template-columns: 1fr; }`、`.score-control .score-inputs { grid-template-columns: 1fr; row-gap: var(--spacing-sm); }`
  - 宽度约束：`.filter-item input, .filter-item select { width: 100%; min-width: 0; }`、`#schoolScoreRange { width: 100%; }`
- 学校名称与标签
  - 名称完整显示并紧凑：`.school-name { flex: 1 1 100%; white-space: normal; line-height: 1.4; font-size: var(--font-size-base); }`
  - 标签自动换行：`.school-header { flex-wrap: wrap; align-items: flex-start; gap: var(--spacing-xs); }`、`.school-header .chip { margin-top: var(--spacing-xs); }`
- 信息密度优化
  - 压缩小屏字体：`.stat { font-size: var(--font-size-xs); }`、`.chip { font-size: var(--font-size-xs); }`
  - 推荐条标签缩短：手机端将推荐条标签列宽从 100px 降为 80px：`.recommend { grid-template-columns: 80px 1fr; }`
  - 保留国家隐藏：`.school-meta .chip.country { display: none; }`

## 验证
- 320–480px 下：过滤栈叠、卡片不溢出；大学名称完整显示、标签换至下一行；推荐条与统计文本在窄屏仍可读。

## 交付
- 一次性更新 `style.css`，不修改 JS 与 HTML。
