## 目标
- 在手机端保证大学名称不被省略，完整显示；同时提升可读性并避免内容溢出。

## 方案（仅改 CSS，不改 JS/HTML）
- 标题行换行：让标题行内标签（类型/匹配类别）自动换到下一行，标题独占一行。
- 名称样式：允许正常换行、提高行高、在手机端适度缩小字号以减少换行次数，但不省略任何字符。
- 溢出控制：卡片内容隐藏溢出边界，避免“板块外溢”。
- 降噪精简：在手机端隐藏 `country` 标签，减少宽度占用。

## 具体样式（@media max-width: 480px）
- `.school-header { flex-wrap: wrap; align-items: flex-start; gap: 0.25rem; }`
- `.school-name { flex: 1 1 100%; white-space: normal; line-height: 1.4; font-size: var(--font-size-base); }`
- `.school-card { overflow: hidden; }`
- `.school-header .chip { margin-top: 0.25rem; }`
- `.school-meta .chip.country { display: none; }`

## 验证
- 320–480 像素屏宽：标题完整显示、不省略；标签换到下一行，内容不越界，无横向滚动。
