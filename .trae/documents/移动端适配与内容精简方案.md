## 目标
- 适配手机与平板，消除横向滚动；在手机端适当精简非核心内容，保留计算与院校推荐主流程。

## 调整点
- 结构：不改动 JS 逻辑，仅通过 CSS 响应式控制显示与布局。
- 手机端内容精简：
  - 隐藏说明区（Instructions Section）。
  - 隐藏分数明细（Score Breakdown）。
  - 隐藏分析区的详细列表，仅保留等级徽章与标题（隐藏 Analysis Grid 与 Study Advice）。
- 布局防溢出：
  - 强制 `html, body` 无横向滚动。
  - 学校结果栅格在小屏强制单列（避免 280px 最小宽导致溢出）。
  - 过滤栏在小屏强制单列。
  - 学校名称允许自动换行，避免超长字符串导致溢出。

## 具体改动（style.css）
- 全局：`html, body { overflow-x: hidden; }`
- 结果栅格：`@media (max-width: 480px) { .results-grid { grid-template-columns: 1fr; } }`
- 过滤栏：`@media (max-width: 480px) { .filters-bar { grid-template-columns: 1fr; } }`
- 学校名称：`.school-name { overflow-wrap: anywhere; word-break: break-word; }`
- 手机端隐藏：
  - `@media (max-width: 480px) { .instructions-section, .score-breakdown, .analysis-card .analysis-grid, .analysis-card .advice { display: none; } }`

## 验证
- 在 320–480 像素屏宽下，无横向滚动；卡片与过滤控件单列展示，名称自动换行。
- 分数计算与院校推荐功能正常；说明与详单不显示，界面更简洁。

## 交付
- 仅修改 `style.css`，不增加文件、不修改 JS 或 HTML 结构。
